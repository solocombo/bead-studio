# Notion 珠子資料庫欄位

在 Notion 建一個「資料庫（表格）」，欄位名稱要**完全一致**（同步程式靠名稱對應）。一列 = 一種珠子。

| 欄位名稱 | 類型 | 必填 | 說明 |
|---|---|---|---|
| 名稱 | 標題 (Title) | ✔ | 例：紫水晶 |
| 代碼 | 文字 (Text) | 建議 | 唯一代碼，英數字，例：`ame8`。訂單用它辨識珠子，**建立後不要改**。留空會用頁面 ID。 |
| 分類 | 單選 (Select) | ✔ | `主珠`／`隔片`／`隔珠` |
| 外觀 | 單選 (Select) | | `寶石`／`珍珠`／`金屬`／`隔片`。沒照片時決定畫法，留空依分類判斷。 |
| 色系 | 單選 (Select) | ✔ | `白透`／`灰`／`黑`／`綠`／`黃金`／`粉`／`紫`／`藍`（對應網頁顏色篩選） |
| 直徑mm | 數字 (Number) | ✔ | 圓珠直徑；隔片填高度 |
| 佔寬mm | 數字 (Number) | 隔片必填 | 串在繩上佔的長度。圓珠留空（= 直徑） |
| 單價 | 數字 (Number) | ✔ | 每顆價格（新台幣） |
| 產地 | 文字 (Text) | | 例：巴西、烏拉圭 |
| 等級 | 文字 (Text) | | 例：A（紫色飽和、條紋清楚） |
| 生日石 | 多選 (Multi-select) | | `1月` ～ `12月` |
| 標籤 | 多選 (Multi-select) | | 自由標籤，會顯示在介紹頁 |
| 照片 | 檔案與媒體 (Files & media) | | 最多 3 張，每顆珠子隨機用其中一張 |
| 上架 | 核取方塊 (Checkbox) | | 勾選才會出現在網頁 |
| 排序 | 數字 (Number) | | 小的排前面 |

## 頁面內文

點開每一列的頁面，用**標題**分段，網頁介紹頁會對應到三個區塊：

```
## 價格說明
- 單顆計價
- 紫色越深越飽和，價格越高

## 故事
紫水晶的紫色來自石英中的微量鐵元素與天然輻射……

## 寓意
二月的生日石，寓意智慧與冷靜。
```

支援：段落、項目符號清單、編號清單、**粗體**。其他區塊（圖片、表格等）會略過。

## 照片規格

- 去背 PNG（或 WebP），正方形
- 珠子置中，直徑約佔畫面寬度 90%
- 統一光源、正上方俯拍
- 隔片拍側面，串線方向保持水平
- 單張建議 500×500 px 以內、200 KB 以下（Notion 免費版單檔上傳上限 5 MB）

## 連結到程式

1. 到 <https://www.notion.so/profile/integrations> 建立一個 Internal integration，複製 token（`ntn_` 開頭）。
2. 打開資料庫頁面 → 右上角 `•••` → **連結（Connections）** → 加入剛剛的 integration。
3. 資料庫網址 `https://www.notion.so/xxxx/<這段32碼>?v=...` 中間那 32 碼就是 `NOTION_DATABASE_ID`。
